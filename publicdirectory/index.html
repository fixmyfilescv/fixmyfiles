      Questions

      Are my files uploaded anywhere?

      No. Every tool runs inside your browser tab, using your device’s own processor and codecs. There is no upload server to send a file to. The counter in the header shows the bytes this page has sent, and it stays at zero.

      Is FixMyFiles free?

      Yes, with no sign-up, watermark or daily cap. Your device does the work, so there is no server bill to pass on to you.

      Is there a file size limit?

      No fixed limit. The ceiling is your own device’s memory, so a two-hour 4K video is slower on a phone than on a laptop, but nothing is refused for being too big.

      Does it work offline?

      Yes, once a page has loaded. A few heavy formats need a one-time engine download the first time you use them, and the page tells you before it happens. See using it offline.

      How do I get a file under a size limit?

      Pick where it is going (Gmail, WhatsApp, Discord, a visa portal) or type the limit. The tool works backwards from that number instead of asking you to guess a quality setting. The upload limits page lists every limit we know.

      Got a file waiting to be fixed?

      Drop it at the top of the page, or open any tool. Nothing is uploaded.

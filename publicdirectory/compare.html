Compare

How this compares to the big converters

They convert more kinds of file than we do, and for documents, ebooks and CAD they are the right answer. For images, video and audio the difference is simpler than a feature table: their way, the file is uploaded; our way, it never leaves the tab.

  • vs CloudConvert FixMyFiles vs CloudConvert CloudConvert converts far more kinds of file than we do — documents, spreadsheets, ebooks, CAD — and has a proper API for automation. For images, video and audio, the difference is that CloudConvert uploads your file to its servers and we never do..
  • vs Convertio FixMyFiles vs Convertio Convertio and FixMyFiles look similar — drop a file in a web page, get a converted one back. The difference is underneath: Convertio sends the file to its servers to do the work, and its free tier is metered by file size and volume as a result..
  • vs FreeConvert FixMyFiles vs FreeConvert FreeConvert covers a wide range of formats and adds useful extras like compression targets. It is still a server-side service, so the free tier is capped by file size and every conversion starts with an upload.
  • vs Online-Convert FixMyFiles vs Online-Convert Online-Convert has one of the deepest format lists anywhere and exposes settings most converters hide. It is server-side, so files are uploaded and the free tier is metered.
  • vs Zamzar FixMyFiles vs Zamzar Zamzar has been converting files online since 2006 and covers a very wide range of document and media formats. It is server-side and its free tier is limited by file size and conversions per day.

What we do not compare

PDF tools, and services built around them, are missing on purpose — we do not convert PDFs, so there would be nothing honest to say. Document, ebook and CAD conversion is the same: a browser cannot open those formats, and a comparison page that implied otherwise would waste your time.

No prices or free-tier quotas appear anywhere in these comparisons either. They change without notice, and a static page that quotes them is wrong within months. Each page links to the service’s own pricing so you can read the current terms there.

Choosing formats, not services

If the question is which format to use rather than which site, the guides settle those: PNG against JPG, MP4 against MKV, MP3 against WAV and the rest.
